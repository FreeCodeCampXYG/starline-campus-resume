# 事实源与岗位投影

## 目的

把“候选人长期做过什么”和“这次岗位需要看见什么”分开。事实源可以跨岗位复用，岗位投影只保留与目标岗位相关的已确认内容。

## 推荐分层

### 事实源

可用 Markdown、访谈账本或本地知识库记录长期事实。每条事实至少包含：经历或项目名称、时间、组织和角色、个人动作与边界、结果/规模/约束、`evidence_type`、来源备注以及待确认项。

Markdown 适合作为人工维护的阅读入口；生成前仍需转换为 `resume-data.json`，让现有验证器检查字段、证据和占位符。

### 岗位投影

每个目标岗位单独生成一份 `resume-data.json`，只改变目标岗位和公司类型、简介与技能排序、项目/经历顺序、bullet 取舍，以及页数、语言和主题。

不得因为 JD 出现某个词，就把它加入事实源或技能栏。缺少证据的要求进入缺口清单，不进入候选人经历。

## 人工确认门

1. 先展示本次投影选中的事实、舍弃的事实和仍有疑点；
2. 用户确认后生成 HTML/PDF；
3. 浏览器内编辑只视为排版草稿；
4. 若编辑改变事实、数字、时间或技能，必须回写事实源并再次确认；
5. 最终交付同时保留 JSON 验证报告，避免只凭视觉判断。

## 多方向复用

同一份事实可以分别投影为后端、AI 应用、数据或医疗信息化方向。每份投影共享事实证据，但允许有不同的标题、顺序和取舍。不要复制出多份互相漂移的“主简历”。

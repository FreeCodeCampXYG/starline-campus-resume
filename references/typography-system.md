# 字体与印刷排版系统

## 目标

让姓名、岗位、联系方式、机构名称、日期和成果描述形成稳定的三秒扫描路径，同时保持单栏 ATS 文本顺序。美观来自字形配对、字号阶梯、字重、对齐和留白，不来自照片、图标、边框卡片或复杂装饰。

## 四种字体机制

### 正式衬线

- 适用：`ats-classic`、`compact`、`rc-003`、`rc-109`、`rc-150`。
- 拉丁与数字：Palatino → Georgia。
- 中文：Songti SC → STSong → SimSun。
- 原因：拉丁字体放在中文字体之前，邮箱、GPA、日期和技术名词不会再使用宋体自带的弱拉丁字形；中文缺字会自然回退到宋体。

### 编辑式

- 适用：`kami`。
- 拉丁与数字：Palatino → Georgia。
- 中文：TsangerJinKai02 W04；标题在本机存在 W05 时使用 500 字重，否则降级到 400，不合成虚假粗体。
- 正文行高与章节间距比其他主题更宽，形成编辑式呼吸感。

### 现代无衬线

- 适用：`swiss`、`campus`、`rc-071`、`rc-214`。
- 拉丁与数字：Avenir Next → Helvetica Neue。
- 中文：PingFang SC → Hiragino Sans GB → Microsoft YaHei。
- 姓名、章节与机构名使用 600；正文使用 400。

### 技术元信息

- 适用：`tech`、`rc-102`。
- 正文与标题：IBM Plex Sans → Avenir Next → PingFang SC。
- 等宽字体仅用于日期、奖项时间和技能标签：SF Mono → Menlo → Monaco → PingFang SC。
- 禁止用等宽字体承担整段中文标题或正文。

所有字体均为本机字体栈，没有远程字体、脚本或图片依赖。未安装首选拉丁字体时按字体栈逐级回退；中文 PDF 仍必须证明目标中文字体实际嵌入。

## 印刷字阶

每个主题可以在受控范围内变化，但角色不可混淆：

| 角色 | 建议范围 | 字重 |
|---|---:|---:|
| 姓名 | 22.5–29pt | 500/600 |
| 章节标题 | 10.3–11.5pt | 500/600 |
| 机构或项目名 | 10–10.45pt | 500/600 |
| 正文 | 9.1–9.55pt | 400 |
| 副标题 | 8.5–9pt | 400 |
| 日期与元信息 | 8.2–8.75pt | 400 |

- 普通主题正文行高 1.44–1.48；Kami 为 1.52；Compact 为 1.34。
- 中文正文不使用负字距；字距只用于姓名或章节标题。
- 日期、电话、GPA、奖项时间使用 `lining-nums tabular-nums`。
- 日期范围使用窄不换行空格包围的连接号：`2025.03 – 2025.06`。
- CSS 打印尺寸只能使用 pt、mm 或 em；禁止 px。

## 混排规范

- 中文与英文、中文与数字之间保留一个正常空格：`完成 8 个 REST API`、`使用 Java 开发`。
- 数字与单位之间留空格，百分号除外：`20 MB`、`前 15%`。
- 中文使用全角标点；链接与技术名词保留官方大小写，例如 `Java`、`Python`、`GitHub`。
- 全部主题禁止 `font-style: italic`；强调使用字重、色彩或字号。
- 项目链接是带细下划线的纯文本，不使用胶囊、色块或按钮外形。

## 空间节奏

- 组内间距必须小于组间间距。
- 章节间距由主题令牌控制；Kami 最宽，Compact 最紧。
- 日期右缘必须对齐；机构名区域可伸缩，日期不得折行。
- 技能标签列使用 em 宽度随字体自适应，不使用固定 px。
- 演示数据较少时保留页尾留白，不用弱经历或空话填满页面。

## 允许与禁止

- 边框声明只允许横向 `border-bottom` 分割线。
- 可使用无轮廓、无圆角的浅色页头 wash 或完整横向章节色带；不得形成卡片、侧栏或包围框。
- 禁止 `border-radius`、`border`、顶边、左/右边、outline、竖线装饰、照片、图标、二维码和进度条。

## 验收

生成 HTML 后，验证器必须确认：

- `resume-typography-system=1.4`；
- 目标中文字体与拉丁字体层都已声明；
- px、italic、链接色块、圆角和禁止边框声明均为 0；
- PDF 中中文字体已嵌入，数字与日期未换行错位；
- 页面实际查看无裁切、重叠、异常断行或视觉层级倒置。
